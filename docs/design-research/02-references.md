## J · Dribbble taste sweeps (broader)

Searches: ascii website · dot matrix ui · swiss style portfolio · brutalist portfolio website · editorial personal website · pixel art website · technical hud interface · awwwards developer. Sheets: `img/ref-j*.jpg`.

- **ASCII:** mostly dark agency sites with ASCII textures; best idea is ASCII as *texture behind* a real headline, not as content.
- **Dot matrix:** smart-device dashboards — dot-matrix numerals for a single big stat (e.g. `2.6×`).
- **Swiss:** red geometric blocks, Helvetica-grade grotesk, rigid grid; "one pixel at a time" headline cliché.
- **Brutalist:** giant names, collage; too loud for an engineer, but **raw borders + system font** is fine.
- **Editorial:** magazine grids with photography — only useful if we have strong photos.
- **Pixel art:** "Launch Week" pixel display type, pixel-scene heroes (Railway-style). Use pixel type for *one* element (name or OLED), never body.
- **HUD:** radar rings, green-on-black telemetry; borrow only the **tick-ring / gauge** for a single stat.
- **Awwwards dev:** award-tier dev portfolios are agency showreels (3D, WebGL, cursor tricks) — wrong genre for an engineer CV.
